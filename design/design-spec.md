## 0. 最初に伝えたいこと

1. **AI は追加費用なしで組み込めます。**【事実】Apple の Foundation Models フレームワーク（端末の中で動く Apple 製の AI を、アプリから呼び出す仕組み）は、Apple Intelligence が対応する言語で読み書きでき、日本語が入っています [A1][A2]。【二次情報】端末内で動くため利用ごとの料金がかかりません [B1]。
2. **AI が動く機種は限られます。**【事実】iPhone 15 Pro／15 Pro Max、iPhone 16 以降、iPhone Air、iPhone Duo、M1 以降の iPad と Mac など [A2]。Shogo さんの iPhone 17 Pro Max は対象です。非対応の機種では AI の機能を出さず、「記録」と手入力だけで成り立つようにします。
3. **Google カレンダー連携は、最初は iPhone の設定に登録済みのカレンダーを使う方式です。** Apple の EventKit（カレンダーを読み書きする公式の仕組み）経由で、Google・iCloud・Outlook をまとめて扱います。直接つなぐ方式は、【事実】カレンダーの予定を読む権限が Google の審査対象で、審査の目安は3〜5営業日です [G1]。後回しにします。
4. **「何でもできる」は伝わりにくいので、入口の言葉を1つに絞ります。**【推測】ストアでの一言は「予定も、推し活も、収支も。写真で残せるカレンダー」。
5. **競馬・競艇・FX の扱い。**【二次情報】Apple の審査の決まりは「実際のお金を賭ける遊びを提供するアプリ」に免許などを求めるものです [B5]。このアプリは記録をつけるだけで、購入・予想の販売・賭けへの誘導はしません。【不明】審査の決まりの原文は今回読めていません。【推測】記録だけなら対象外と考えますが、審査で聞かれたら「記録専用」と説明できる作りにします（外部の投票サイトへのリンクを置かない、など）。
6. **「推しの情報を自動で拾う」は第2弾のままです。**【推測】自前のサーバーと、情報元の利用条件の確認が要るためです。
7. **売れるかは未検証です。**【二次情報】Fantastical は月1,000円・年10,000円、TimeTree プレミアムは月300円・年3,000円 [B2]。標準カレンダーは無料です。価格は 年額4,800円／月額500円／買い切り9,800円 の3本立てに決定（2026年11月11日）。
8. **アプリ名「ペタカレ」は仮称です。**【不明】商標と App Store での重複は未確認。

### A-1. 要件

**目的（1文）**：予定と、その日の記録（写真・金額・メモ）を、貼る・選ぶ・送るだけで同じカレンダーに残せるようにする。

**利用者**：推し活の予定と出費を残したい人、FX・競馬・競艇などの収支を毎日つけたい人、予定の連絡を LINE やメールで受け取る人。

### A-3. AI の使いどころ

```
入力（文章／写真／PDF）
  → ① 文字にする（写真は Vision、PDF は PDFKit）
  → ② 日時・金額のあたりを付ける（NSDataDetector と正規表現。AI ではない）
  → ③ 端末内AIで決まった形に直す（予定の候補 または 記録の下書き）
  → ④ 画面に出して人が確かめる（自動では保存しない）
  → ⑤ 予定は EventKit、記録は SwiftData に保存
```

- 記録の下書き：的中画面や取引履歴の写真から、日付・金額・プラスかマイナスか・種目の候補を読み取ります。金額はまちがいが困るので、必ず確認画面を通します。
- 「来週」「18日」などの日付の補完と、金額の合計は、AI ではなくアプリ側の計算で行います。
- AI が使えない機種では②だけで下書きをつくります（回数に数えない）。
- 内容は端末の外に送りません（iCloud 同期は利用者自身の iCloud）。

### A-4. 部品の分け方と状態管理

状態は Swift 標準の Observation（`@Observable`）。外に触る部分は窓口（protocol）で包み、テストで差し替えます。

| 部品 | 役割 |
|---|---|
| `CalendarStore` | EventKit の読み書き |
| `RecordStore` | 記録と写真の保存・検索・同期（SwiftData） |
| `TextExtractor` | 写真・PDF → 文字 |
| `DraftGenerator` | 文字 → 予定の候補／記録の下書き（端末内AI／簡易） |
| `DateResolver`・`SlotFinder`・`StatsCalculator` | 日付の補完、空き時間、集計と予算（AIなしの純粋な計算。そのままテスト） |
| `PhotoGrouper` | 写真を撮影日ごとに分ける |
| `LockGate` | ロックの状態（アプリを閉じたら再ロック） |
| `SummaryRenderer` | まとめ画像をつくる |
| `QuotaStore`・`EntitlementStore` | 無料回数、Pro かどうか |

画面ごとの状態：`CalendarModel`、`RecordListModel`、`RecordEditModel`、`StatsModel`、`CaptureModel`、`ShareModel`、`SlotModel`、`PaywallModel`。

    var memo: String
    var photos: [RecordPhoto]

@Model final class CaptureRecord { ... }   // 取り込みの履歴（第1稿と同じ。取り消し用）

struct EventDraft { ... }                // 予定の候補（第1稿と同じ）

## B. デザイン設計書

### 1. 前提

- 対応：iPhone／iPhone Duo／iPad／Mac（ネイティブ）
- 画面の向き：iPhone と iPhone Duo の外側は縦のみ。iPhone Duo の内側と iPad は全方向。レイアウトはサイズクラス（使える幅と高さ）で決める

- 起動画面：最初の画面の骨格だけ（文字なし、ライト／ダーク別）
- 文言：String Catalogs（最初は日本語のみ）
- アプリアイコン、枠つきの掲載用画像：この設計の範囲外

| 金額 | その日の収支を大きく（＋／−の記号つき）、予定は点 | 収支を毎日つける人 | Pro |
| 写真 | 記録の写真を日ごとに並べる、予定は点 | 推し活・写真中心の人 | Pro |

- 無料版で Pro のパターンを選ぶと、見本を表示したうえで S-07（Pro の案内）を出します。
- Pro をやめたら「帯」に戻します（記録や写真は消えません）。

#### 色分け（設定 → 色分け）

予定と記録の色を、50色の中から自分で選べます。色の雰囲気を丸ごと変える「見た目」の切り替え（スタイリッシュ／かわいい）は作りません（本人の判断で取りやめ）。

- **50色の中身**：10系統（赤・オレンジ・黄・緑・青緑・青・紫・ピンク・茶・グレー）× 5つの調子（あざやか・明るい・うすい・こい・くすみ）。どの色にも「ピンク・あざやか」のような名前があり、VoiceOver で読み上げます。ライト用とダーク用の値を別に持ちます。値は `design/build.py` の `preset()` が正です。
- **色を付けられる単位**：
  1. カレンダーごと（仕事、家族など）。最初は端末のカレンダーの色（「元の色」）。
  2. 記録の種類ごと（推し活、収支・FX、日々の記録など。自分で追加した種目も）。
  3. 予定1件ごと（S-02 の予定のシートに「色」の行を足す）。選ばなければカレンダーの色。
- **選び方**：一覧で行をタップ → 色のシート（50個の丸）→ タップで選ぶ → 右上の完了。シートの下に、月の帯になったときの見本と「最初の色に戻す」（カレンダーは「元の色に戻す」）。
- **保存先**：選んだ色はこのアプリの中に保存し、iCloud で全端末にそろえます。元のカレンダー（Google など）の色は書き換えません。
  - 事実：端末のカレンダーの仕組み（EventKit）では、カレンダーの色（`EKCalendar.cgColor`）は読み書きできます。
  - 確認できた範囲：予定1件ごとの色を持つ項目は、読んだ資料（`EKCalendarItem` の一覧。一部のみ表示）には見当たりません。全項目は未確認。
  - このため、予定1件ごとの色は Google カレンダー側の「予定の色」とは連動しません（Google で付けた予定の色は読めず、こちらで付けた色も Google には出ません）。
- **色だけに頼らない**：帯には必ず題名が入り、一覧にはカレンダー名・種類の名前が出ます。収支の＋／−は記号でも示します（これまでどおり）。
- **無料／Pro**：50色すべて無料（提案）。
- **データ**：`ColorChoice`（対象の種類：カレンダー／記録の種類／予定、対象のID、色の番号 0〜49）を SwiftData に持ち、iCloud で同期。色の番号と値の対応表は PetaCore に置いてテストを付けます。

### 4. プラットフォーム別

**iPhone**：題名の下に「日／週／月」の切り替え。月は画面いっぱいの格子で、1日に予定の帯を3本まで（入りきらない分は「ほか○件」）、その下に記録の印（四角）と金額。日をタップすると、その日の予定と記録が下からシートで出る（大きさを変えられるので、つまみ付き）。予定をタップすると S-02 のシート。最大文字サイズでは「日」の表示を既定にし、月の帯は題名を出さず本数だけにする（**このときのモックは作り直していません**）。S-10 の行は、最大文字サイズで金額を題名の下の行に移す。

**iPhone Duo**：外側は1段（月の金額は省き、点だけ）。内側の横向きは左に月（金額つき）、右に日の一覧。半分折ったときは左右均等で、中央 ±13pt に何も置かない。内側の Split View（画面の半分）では外側と同じ1段。バーの位置は近似。あふれるときは ＋ → タブ → 検索 → 候補日 の順に残す。

**iPad**：横向きは月の格子（予定の題名と記録の金額の帯）＋右に日の一覧。細いウィンドウでは点の表示にして一覧を下へ。キーボード：⌘N 記録を追加、⇧⌘N 予定を取り込む、⇧⌘V クリップボードから取り込み、⌘T 今日、⌘F 検索、⌘1〜⌘4 タブ。メニューバーの「表示」に各タブ。

**Mac（ネイティブ）**：メニューバーは ペタカレ → ファイル → 編集 → 表示 → ウインドウ → ヘルプ。サイドバーに カレンダー／記録／集計。設定は「設定…」（⌘,）の別ウィンドウ。ツールバーは1行（題名と今月の合計、今日、候補日、＋、検索）。ウィンドウの最小は 800×560pt（狭いと右の日の一覧を先に隠す）。ロックは Touch ID かパスワード。ショートカットは iPad と同じ。

S-09〜S-14 の iPad・Mac・iPhone Duo 内側での見え方：どれもシート（iPad はフォームシート、Mac はウィンドウのシート、Duo 内側は中央のシート）の中に iPhone と同じ並びで出します。S-10・S-11 は、広い画面では一覧（左）＋詳細（右）の2列にします。**これらのモックは iPhone だけ描いています。**

### 5. アクセシビリティ
