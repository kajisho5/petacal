プライバシーポリシーお問い合わせサポート

SEVENTHWELL（以下「私たち」）は、iPhone・iPad・Mac 向けアプリ「ペタカレ」（以下「本アプリ」）で扱う情報について、次のとおり定めます。

1. 集める情報

私たちは、本アプリを通じて、あなたの予定・記録・写真・メモ・金額、そのほかあなたを特定できる情報を集めません。本アプリには、私たちのサーバーへ情報を送る仕組み、広告、利用状況の分析、外部の分析サービスは入っていません。

2. 端末の中で扱う情報

  • 予定：端末に登録してあるカレンダーを、あなたの許可を得たうえで読み書きします。予定の内容は端末の中だけで扱います。
  • 記録と写真：記録・金額・メモ・写真は、あなたの端末に保存します。
  • 文字の読み取りと AI：写真や文章からの日付・金額の読み取り、対応する端末での AI による題名や場所の読み取りは、すべて端末の中で行います。
  • 通知：予算のお知らせは端末の中でつくります。通知の文に金額は入れません。

3. Google のデータ

本アプリの設定から Google アカウントと直接つないだときに限り、本アプリは Google Calendar API を使って次の情報を扱います。

  • 読むもの：カレンダーの一覧（名前と色）、予定（題名・日時・場所・メモ・色）、予定の色の定義。アカウントのメールアドレスは、メインのカレンダーの ID として読み取ります。
  • 書くもの：あなたが本アプリで追加・変更・削除した予定だけ。
  • 使い道：本アプリの画面に表示し、あなたの操作どおりに予定を保存するためだけに使います。広告、利用状況の分析、AI の学習には使いません。
  • 保存場所：ログインの情報（トークン）は端末のキーチェーンに、読み込んだ予定は端末の中に保存します。私たちのサーバーには送らず、第三者にも渡しません。
  • 削除：設定の「接続を解除」で、Google でのアクセス許可を取り消し、端末の中のログインの情報と予定を消します。Google カレンダー側の予定は消えません。Google アカウントの設定（サードパーティのアクセス）からも取り消せます。

本アプリが Google API から受け取った情報の利用と、ほかのアプリへの転送は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

Petacal's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

4. 購入

本アプリの App 内課金は Apple が手続きを行います。私たちが知ることができるのは、Apple が提供する売上の集計（あなたを特定しない件数や金額）だけで、氏名やお支払いの情報は受け取りません。購入したプランの確認は、あなたの端末の中で行います。Apple による情報の扱いは、Apple のプライバシーポリシーをご覧ください。

5. 第三者への提供

私たちは情報を集めないため、第三者へ提供することはありません。Google のデータも、上の 3. のとおり第三者に渡しません。

6. 情報の削除

本アプリのデータは、本アプリを削除すると端末から消えます。カレンダーの予定は、カレンダーのアカウント（iCloud や Google など）側に残ります。

7. お子さまの利用

本アプリは、年齢にかかわらず、情報を集めずに使えます。

8. このポリシーの変更

内容を変えるときは、このページを更新し、上の日付を改めます。
